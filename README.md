# Спин Арена

Настольный теннис в 3D прямо в браузере: один на один против робота X-Бота или вдвоём на одном телефоне.

## Как играть

- **Палец — это ракетка.** Ведите им влево и вправо: голубое кольцо на полу — ракетка, белая точка — куда прилетит мяч. Совместите их, и мяч отобьётся.
- **Резко двиньте палец вперёд в момент удара** — сильный удар. Движение вбок — направление. Палец стоит — мягкий блок. Резко назад — подрезка.
- **Топспин**: коротко отведите палец назад и сразу резко вперёд. **Дуга** — боковое вращение (и на подаче). Цвет следа мяча показывает вращение: голубой — верхнее, фиолетовый — нижнее, мятный — боковое.
- **Серединой ракетки** (кольцо зелёное) удар точный, сильный удар становится КРИТом. Три точных удара подряд заряжают СУПЕРУДАР. Краем мяч уводит.
- **Кольцо на столе** появляется после удара соперника и показывает, куда упадёт мяч.
- **Вдвоём** — нижняя половина экрана у Игрока 1, верхняя у Игрока 2. Подача: свайп к сопернику, тап — короткая.

## Как устроено

Статический сайт без сборки: `index.html` и ES-модули из `js/`.

| Файл | Что делает |
| --- | --- |
| `js/physics.js` | Полёт мяча: сопротивление воздуха, эффект Магнуса, отскок с учётом вращения, решатель траекторий |
| `js/athlete.js` | Персонажи со скелетом, обратная кинематика рук и ног, траектория ракетки |
| `js/match.js` | Правила, счёт, подачи, компьютерный соперник |
| `js/scene.js` | Арена, стол, трибуны, свет |
| `js/fx.js` | След мяча, искры, кольца, синтезированные звуки |
| `js/main.js` | Камера и облёты, управление свайпами, интерфейс |
| `models/` | Модели персонажей (glTF в base64) |

three.js 0.160 загружается с cdn.jsdelivr.net.

Запуск локально: любой статический сервер из этой папки, например `npx serve .`

## Авторство

- Движок: [three.js](https://threejs.org) (MIT).
- Модели Michelle и X Bot взяты из примеров three.js (`examples/models/gltf`), исходно сделаны в Adobe Mixamo. Анимации удалены, геометрия квантована через glTF-Transform.
